# 일러스트 관리

- `/admin/`에서 **세로형 일러스트 관리** 또는 **가로형 일러스트 관리**를 선택하고 편집 화면을 엽니다.
- 썸네일을 원하는 위치에 드래그하거나 앞/뒤 버튼을 눌러 순서를 변경합니다.
- 아래 작품 목록을 펼쳐 제목과 이미지를 수정하거나 작품을 추가/삭제합니다. 기존 이미지 업로드 기능을 사용합니다.
- 화면 상단의 저장 버튼으로 변경 내용을 저장합니다. 방향별로 따로 저장합니다.
- 모바일이나 키보드에서는 썸네일의 이동 버튼을 사용할 수 있습니다.

실제 작품 데이터와 순서는 `content/gallery-vertical.json`, `content/gallery-horizontal.json`의 `items` 배열에 저장됩니다. 사이트는 이 파일을 직접 읽으며 `node merge-data.js`도 같은 순서로 병합합니다. 새 작품의 위치는 목록에서 조정할 수 있고, 제목이나 이미지를 수정해도 순서는 유지됩니다.

기존 `content/gallery/*.json`은 이전 데이터 보관용으로 남겼습니다. 이후 이 폴더를 수정해도 사이트에는 반영되지 않습니다. 최초 이전 시 방향이 없던 작품은 기존 사이트의 동작대로 세로형에 포함했습니다.

로컬 CMS 편집에는 기존과 같이 사이트 HTTP 서버와 `npx decap-server`가 필요합니다. 배포 사이트의 저장은 기존 Netlify Identity / Git Gateway 로그인을 사용합니다.
